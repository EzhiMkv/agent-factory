# spec-delta: 003-critter-core

## NEW — контракты (packages/contracts)

1. **Critter** (`src/Critter.sol`): минт бесплатно от деплоера; существо
   = ERC-721 с детерминированной ДНК (uint256 сид из хеша), полями
   stage 0..2, level, сытость/счастье/энергия (uint8 0..100).
   События: `Hatched(dnaSeed)`, `Fed(delta)`, `Played(delta)`,
   `Slept(delta)`, `Evolved(stage)`. Каждый акт заботы — отдельный
   контрактный вызов. Деградации по времени нет (TZ: таймеры рвут демо).
2. **Рендер он-чейн арт** (`src/render.sol`): `tokenURI` → data-URI SVG
   желейки, собранной из ДНК (цвет тела 24-бит, форма глаз, узор).
   Без внешних запросов и IPFS.
3. **ERC-6551 TBA** (`src/erc6551/`): минимальные `Registry` и
   `TokenBoundAccount`; с каждым пухликом ассоциирован собственный
   кошелёк; при эволюции в этот кошелёк минтится ачивка.
