## tc-02
- [x] контракт Critter: хатч из ДНК-сида, минт демо-аккаунту, события Hatched, тесты Foundry
  - Файлы: `packages/contracts/src/Critter.sol`,
    `packages/contracts/test/Critter.t.sol`
  - Требования: ERC-721 минимально (mint/ownerOf/tokenURI заглушка до
    tc-03); ДНК = uint256 сид от адресов+time (keccak); структура
    `dnaSeed, stage=0, level=0, сытость=80, счастье=70, энергия=90`;
    `mintTo(address to)` бесплатно только от деплоера; событие
    `Hatched(uint256 dnaSeed)`; getter `critter(uint256)` → статус-поля.
  - Критерий: `forge test` — минт, ownerOf, событие, отсутствие чужого
    минта (revert), 4+ говорящих тестов.

## tc-03
- [ ] он-чейн арт: tokenURI как data-URI SVG желейки из ДНК, снапшот-тест
  - Файлы: `src/render.sol`, тест `test/Render.t.sol`
  - Требования: цвет тела из ДНК (24-бит hex), форма глаз и узор
    выбираются детерминированно от сида; `tokenURI(uint256)` в data:URI
    c `image/svg+xml`; тест репит подстроки SVG
    (начало `data:image/svg+xml;base64,` и выбранные цвета).
  - Критерий: `forge test` — 3+ теста (детерминизм: один сид → один SVG;
    другой сид → другой цвет; URI декодируется как svg+xml).

## tc-04
- [ ] уход: feed/play/sleep обновляют статусы 0..100 с clamp, события Fed/Played/Slept
  - Файлы: `src/Critter.sol`, `test/Critter.t.sol`
  - Требования: функции `feed(uint8)`,`play(uint8)`,`sleep(uint8)` от
    владельца; только по одному живому существу (id == 1 в MVP); входные
    значения клампятся 0..100; play при нулевой энергии — милый revert
    («слишком устал», пухлик зевает).
  - Зависимость: tc-02.
  - Критерий: `forge test` — нижние/верхние clamp-кейсы, revert (не
    владелец, нулевая энергия), события фиксируются (vm.expectEmit).

## tc-05
- [ ] эволюция: level растёт от актов заботы, пороги → stage 0..2, событие Evolved
  - Файлы: `src/Critter.sol`, `test/Evolution.t.sol`
  - Требования: каждый акт +1 ур. за акт; пороги: 5 → stage 1, 15 →
    stage 2 (стадия только растёт); событие
    `Evolved(uint8 stage)`.
  - Зависимость: tc-04.
  - Критерий: `forge test` — ход через порог ровно в момент 5-го и 15-го
    акта; повторная эволюция не событиится.
