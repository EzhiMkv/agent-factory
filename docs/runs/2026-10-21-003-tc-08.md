# Прогон 2026-10-21 — 003-tc-08 ачивка за эволюцию: минт milestone-NFT в TBA

- Спека: `openspec/changes/003-critter-core/tasks.md#tc-08`
- Агент: Qoder general-purpose agent, ветка `work/003-critter-core/tc-08`
- Постановка: достижение `stage ≥ 1` → минт milestone-NFT в кошелёк TBA
  пухлика (safeTransfer к account); getter ачивок для owner-а UI.

## Что сделано
- `src/Achievements.sol` (~110 строк): milestone-ERC721; хук
  `onEvolved(tokenId, stage)` минтит ачивку сразу в предсказанный TBA-адрес
  (`registry.account` с теми же параметрами, что `createAccount`),
  safeTransfer-семантика через проверку `onERC721Received` у получателя;
  ачивка за каждую эволюцию (stage 1 и 2), идемпотентность по
  `highestAwarded`; геттеры `tbaOf / ownerOf / balanceOf / milestone /
  achievementsOf / highestAwarded` — для UI (tc-12).
- `src/Critter.sol` — минимальный хук (+19 строк): поле `achievements` +
  setter (onlyOwner) + вызов `_unlockMilestone` ровно там, где эмитится
  `Evolved`; хук 0 = прежнее поведение. Critter почти не тронут — конфликт
  с параллельным tc-06 (render.sol) невозможен.
- `src/erc6551/TokenBoundAccount.sol` (+6 строк): `onERC721Received` —
  аккаунт питомца умеет держать NFT (по смыслу ERC-6551).
- Тесты `test/Achievements.t.sol` (8): критерий тикета «после эволюции
  баланс TBA == 1», чужие вызовы хука revert, вторая эволюция → вторая
  ачивка, идемпотентность хука, минт до деплоя TBA, предсказание адреса,
  работа без хука.
- Дизайн-решения зафиксированы в `docs/runs/2026-10-21-003-tc-08-plan.md`.

## Итерации и проблемы
- Один красный цикл компиляции: кириллица в обычной строке `assertEq` →
  «Invalid character in string» → исправлено на `unicode"..."` литерал.
- Worktree создан до свежего main (ушёл judge-отчёт tc-06) — заметил по
  «удалению» чужого файла в `git diff main`; вылечено fast-forward до
  `782c1fe`, конфликтов не было.
- Дизайн-развилка «push vs pull»: спека требует «достижение stage ≥ 1 →
  минт», поэтому выбран push-хук из Critter (ачивка атомарна с эволюцией),
  а не pull-контракт, слушающий событие; минт на предсказанный адрес
  работает и если TBA ещё не создан (assets прицепляются после createAccount).
- Известное ограничение: `Deploy.s.sol` (tc-13) пока не деплоит
  Achievements и не вызывает `setAchievements` — деплой-скрипт вне зоны
  тикета; для демо-сети нужен добор при интеграции, иначе ачивки не минтятся.
