## Итерации и проблемы
- «Ожидаемый хвост» в доках показывал impl = `0xDc64…` — это адрес
  второго прогона на used-сети (nonce 4). На свежем anvil impl =
  `0x5FbD…` (nonce 0). В доках теперь свежие адреса, оговорка про сдвиг
  адресов по nonce и контрольный `cast call ownerOf(1)`.
- Шаг 3 доков (`forge script --verify`) молча предполагал ключ
  верификатора: forge 1.2.3-stable читает `ETHERSCAN_API_KEY` (проверено
  по `forge script --help`), а не `BASESCAN_API_KEY` из `.env.example` —
  в команду добавлен явный проброс
  `ETHERSCAN_API_KEY=$BASESCAN_API_KEY`.
- `cast wallet address` не читает `DEPLOYER_PRIVATE_KEY` — падает
  «Failed to decode private key» (шаг 1 доков был нерабочим). Переписан
  на проверенную связку `set -a && source .env && set +a` + `cast wallet
  address --private-key "$DEPLOYER_PRIVATE_KEY"` (печатает 0xf39F…,
  в истории команд остаётся только имя переменной).
- Переменные `$BASE_SEPOLIA_RPC_URL` и иже с ними — шелл-подстановки и
  из `.env` сами не подставляются: в шаг 0 добавлен
  `set -a && source .env && set +a`.
