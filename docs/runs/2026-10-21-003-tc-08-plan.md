# План прогона 2026-10-21 — 003-tc-08 ачивка за эволюцию в TBA

- Спека: `openspec/changes/003-critter-core/tasks.md#tc-08`
- Агент: Qoder general-purpose agent, ветка `work/003-critter-core/tc-08`
- Постановка: достижение `stage ≥ 1` → минт milestone-NFT в кошелёк TBA
  пухлика (safeTransfer к account); getter ачивок для owner-а UI.
- Зависимости: tc-05 (Evolved, пороги 5/15) и tc-07 (Registry + TBA) — в main.

## Дизайн-решения (минимально разумные)

1. **Кто минтит:** отдельный контракт `src/Achievements.sol`; Critter дёргает
   **минимальный хук** — одно поле `achievements` + setter (onlyOwner) +
   вызов `IEvolutionHook.onEvolved(tokenId, stage)` в `_afterCareAct` ровно
   в тех местах, где эмитится `Evolved`. Хук выключен, пока адрес 0 —
   существующее поведение (и тесты tc-02..tc-05) не меняются. Critter.sol —
   дифф ~15 строк, чтобы не конфликтовать с параллельным tc-06 (render.sol).
2. **Безопасность:** `onEvolved` принимает вызовы только от контракта
   Critter (`msg.sender == critter`, иначе revert NotCritter) — ачивку
   нельзя подделать чужой транзакцией. Идемпотентность: стадия монотонна,
   повторный вызов с не-большей стадией — тихий no-op (уход не ломается).
3. **Связь Registry→TBA:** Achievements в конструкторе получает
   (critter, registry, accountImpl, accountSalt) и вычисляет адрес кошелька
   пухлика через `registry.account(impl, salt, block.chainid, critter, tokenId)`
   — те же параметры, что у `Registry.createAccount`. Хелпер `tbaOf()` —
   для тестов и UI (tc-12). Минт идёт на предсказанный адрес: работает и
   если TBA ещё не задеплоен (assets прицепятся к аккаунту после создания).
4. **safeTransfer-семантика:** минт с проверкой приёмника ERC-721
   (onERC721Received) — для этого TokenBoundAccount получает +4 строки
   `onERC721Received` (аккаунт по смыслу ERC-6551 должен уметь держать
   NFT). tc-07 уже смержен, параллельники этот файл не трогают.
5. **Один milestone-NFT за каждую эволюцию** (стадия 1 и стадия 2) —
   ачивок у пухлика несколько, getter `achievementsOf(critterTokenId)`
   возвращает их id-шники для UI. `tokenURI` не делаю — в тикете не
   запрошено (арт ачивок — кандидат в добор для tc-12, отмечу в логе).
6. **Deploy.s.sol не трогаю** — зона tc-13; прод-деплой потребует добора
   (деплой Achievements + `critter.setAchievements(...)`), фиксирую в логе.
