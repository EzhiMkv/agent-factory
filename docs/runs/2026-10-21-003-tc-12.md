## Что сделано

- `packages/web/src/TbaCard.tsx` + `TbaCard.css` — карточка кошелька
  пухлика (ERC-6551): сокращённый адрес `0x1111…0000` (полный — в
  подсказке title) со scan-ссылкой `sepolia.basescan.org/address/<tba>`,
  ETH-баланс («В кармашке: 0.05 ETH», viem `formatEther` + бережный
  трим хвостов), список ачивок с милыми именами по стадии
  («Первая эволюция»/«Вторая эволюция», fallback для будущих стадий).
- Источник данных — геттеры `Achievements` (tc-08): TBA-адрес резолвится
  через `tbaOf(1)` (registry/impl/соль уже зашиты в контракте — отдельный
  расчёт по Registry не нужен), дальше параллельно `getBalance` /
  `achievementsOf` / `highestAwarded` / `milestone(id)` через
  `Promise.allSettled`: тихий сбой части данных не валит карточку
  (баланс не доехал → «В кармашке пока пустовато :3», остальное на
  месте). Свежая ачивка (stage == `highestAwarded`) — праздничная
  пастельная плашка с мягкой анимацией + prefers-reduced-motion.
- Состояния по образцу CritterView: waiting («Кошелёчек пухлика ещё не
  заселился в сеть — ждём деплой-волшебство :3»), loading («Пыхтим…»),
  sleepy («Пухлик зазевался — попробуем ещё разочек?» + кнопка retry).
  Формулировка waiting намеренно без подстроки «Ждём-ждем деплоя» —
  иначе дублируется с CritterView и ломает smoke-тест getByText.
- Переиспользование: env-паттерн и клиент — как в CritterView
  (read-only публичный клиент: карточка должна жить и без burner-ключа,
  поэтому не через `getCareClients()`), basescan-база — по образцу
  lifeFeed. Дублирования провайдеров нет, тосты/Toasts не тронуты.
- `App.tsx` — интеграция одной строкой `<TbaCard />` (между кнопками
  заботы и лентой). `env.d.ts` + `.env.example` —
  `VITE_REGISTRY_ADDRESS`/`VITE_ACHIEVEMENTS_ADDRESS` (имена совпали с
  теми, что печатает Deploy.s.sol в d710a71); секретов нет.
- Тесты `TbaCard.test.tsx` (8): ждём деплоя без сети, адрес+ссылка,
  баланс через настоящий formatEther, ачивки+праздничная подсветка,
  пустые ачивки, тихий сбой баланса, ошибка сети + retry, хелперы.
  viem мокается частично через `importOriginal` — parseAbi/formatEther/
  isAddress остаются настоящими, сеть — мок (паттерн CritterView.test).

## Итерации и проблемы

- abitype `parseAbi` не принимает имена компонентов внутри `tuple(...)`
  в возврате — переписал `milestone` на мульти-возврат
  `returns (uint256 critterTokenId, uint8 stage)`; в рантайме проверил
  node-скриптом: viem декодирует мульти-возврат **массивом**, а не
  объектом — в компоненте деструктуризация по индексу.
- Первый `pnpm -r test` ушёл в основной репозиторий (cwd не удержался
  между командами) — поймал по путям в выводе и числу тестов 43≠51;
  перезапустил в worktree, там доустановил node_modules
  (`pnpm install --frozen-lockfile`, 1.6 c из общего стора).
- Пока работал, main уехал на два коммита (d710a71 — деплой печатает
  VITE_REGISTRY/VITE_ACHIEVEMENTS; 242dd74 — шпаргалка в AGENTS.md):
  ребейз на 242dd74, конфликтов нет, тесты перегнаны заново — зелёные.

- Дифф тикета ~675 строк (код ~550, остальное — план и лог) — выше
