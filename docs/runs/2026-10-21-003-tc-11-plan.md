# План прогона 2026-10-21 — 003-tc-11 «лента жизни»

- Спека: `openspec/changes/003-critter-core/tasks.md#tc-11`
- Ветка: `work/003-critter-core/tc-11` (worktree `worktrees/003-critter-core-tc-11`)
- Постановка: подписка viem `watchContractEvent` на Fed/Played/Slept/Evolved,
  лента последних 10 событий в UI, каждая запись — ссылка на basescan
  (Base Sepolia, `https://sepolia.basescan.org/tx/<hash>`), Evolved —
  особенный милый баннер.

## Шаги

1. Переиспользовать паттерны: клиент — `getCareClients()` из `wallet.ts`
   (кэш burner-клиента), адрес — `critterAddress()` (env
   `VITE_CRITTER_ADDRESS`), тона тостов — `ToastTone` из `Toast.tsx`,
   тестовые моки viem — по образцу `care.test.ts`.
2. `lifeFeed.ts` — чистая логика:
   - тип `LifeEventKind` (fed/played/slept/evolved) и `ParsedLifeEvent`
     (kind, delta, stage, tx, at);
   - `parseLifeLog(log, nowMs)` — парсинг viem-лога → запись ленты или
     null (неизвестное имя/без tx-хеша);
   - `basescanTxUrl(tx)` — ссылка Base Sepolia;
   - `appendFeed(current, parsed, id)` — новейшие сверху, максимум
     `FEED_MAX = 10`;
   - `lifeEventLine` — няшный копирайт записи, `feedToastTone` — тон
     тоста (evolved → «quiet», остальные мапятся на feed/play/sleep);
   - `watchLifeFeed(onEvent, onError)` — подписка на все 4 события одним
     `watchContractEvent`, возвращает `{ started, stop }` (без адреса/ключа
     — не стартуем, сеть не трогаем).
3. `LifeFeed.tsx` + `LifeFeed.css` — компонент ленты: милые состояния
   (лента спит без деплоя, «пока тихо» в пустой ленте, «сеть притихла»),
   Evolved — праздничная пастельная плашка с мягкой анимацией +
   prefers-reduced-motion. Тосты-события — через существующий `note`
   из `useCareToasts` (проп `note`), без дублирования Toasts.
4. Интеграция в `App.tsx` — одна строка `<LifeFeed note={note} />`.
5. Тесты (vitest, моки viem по паттерну care.test.ts):
   - `lifeFeed.test.ts` — парсинг лога (Fed/Evolved/мусор/без хеша),
     basescan-ссылка, cap 10 и порядок ленты, копирайт, тона тостов,
     подписка (без env — не стартует; onLogs → parsed; onError; stop →
     unwatch);
   - `LifeFeed.test.tsx` — UI: пустая лента, событие прилетает с ссылкой,
     Evolved-баннер + тост, cap 10 в DOM, тихая сеть, спящая лента.
6. Проверка: `pnpm -r test` и `pnpm -r build` (tsc strict) зелёные.
7. Само-ревью `git diff main`, коммиты: логика → UI, без чужих файлов.
