# План прогона 2026-10-21 — 003-tc-12 «карточка TBA»

- Спека: `openspec/changes/003-critter-core/tasks.md#tc-12`
- Ветка: `work/003-critter-core/tc-12` (worktree `worktrees/003-critter-core-tc-12`)
- Постановка: карточка кошелька питомца (ERC-6551 TBA) — сокращённый адрес
  со scan-ссылкой на `sepolia.basescan.org/address/<адрес>`, ETH-баланс
  и ачивки из геттеров Achievements; loading/ошибки — милые (доктрина
  нятости); vitest на мок-данных; strict.

## Шаги

1. Изучить источники: `packages/contracts/src/Achievements.sol`
   (геттеры `tbaOf(tokenId)` — предсказанный TBA-адрес,
   `achievementsOf(tokenId)` → id-шники, `milestone(id)` → {stage},
   `highestAwarded(tokenId)` → последняя награждённая стадия),
   паттерны `CritterView.tsx` (фазы waiting/loading/ready/sleepy,
   env-адрес, retry-кнопка) и `lifeFeed.ts` (basescan-ссылки).
2. Решение по данным: TBA-адрес резолвим через `Achievements.tbaOf(1)`
   (MVP tokenId=1) — там уже зашиты registry/impl/соль, отдельный
   расчёт по Registry не нужен; env добавляем обе переменные
   (`VITE_REGISTRY_ADDRESS`, `VITE_ACHIEVEMENTS_ADDRESS`), чтение —
   achievements-адреса (все нужные геттеры живут там).
3. `TbaCard.tsx` (+`TbaCard.css`) — чистые хелперы и компонент:
   - `shortenAddress`, `basescanAddressUrl`, `formatEth` (viem
     `formatEther` + бережный трим), `achievementName(stage)`
     («Первая эволюция»/«Вторая эволюция», милый fallback);
   - `fetchTbaCard` — tbaOf (критично) + параллельно getBalance /
     achievementsOf / highestAwarded / milestone(*) через
     `Promise.allSettled`: тихий сбой части данных не валит карточку
     (баланс → «В кармашке пока пустовато :3»);
   - фазы: waiting («ждём-ждем деплоя»), loading («пыхтим…»), ready
     (адрес + ссылка + баланс + список ачивок, пустые — «Ачивки ещё в
     пути — пухлик старается!»), sleepy («Пухлик зазевался…» + retry).
4. Доктрина нятости: пастель/желе/мягкие тени в TbaCard.css, свежая
   (highestAwarded) ачивка — праздничная плашка с мягкой анимацией +
   prefers-reduced-motion.
5. Интеграция в `App.tsx` — одна строка `<TbaCard />`; env.d.ts и
   `.env.example` — новые переменные без секретов.
6. Тесты `TbaCard.test.tsx` (паттерн LifeFeed.test.tsx/CritterView.test.tsx,
   viem частично мокаем через importActual — formatEther остаётся
   настоящим): адрес+ссылка, баланс, ачивки с названиями и праздничной
   подсветкой, пустые ачивки, ожидание деплоя, тихий сбой баланса,
   ошибка сети + retry, хелперы.
7. Проверка: `pnpm -r test` и `pnpm -r build` (tsc strict) зелёные.
8. Само-ревью `git diff main`, коммит(ы) `(<003-tc-12>) …`, лог прогона.
