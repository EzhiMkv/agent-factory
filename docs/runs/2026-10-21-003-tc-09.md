# Прогон 2026-10-21 — 003-tc-09 web сцена: пухлик из tokenURI, реакции корм/игра/сон

- Спека: `openspec/changes/003-critter-core/tasks.md#tc-09`
- Агент: opencode (GLM), ветка `work/003-critter-core/tc-09`
- Постановка: web сцена — пухлик из on-chain tokenURI, реакции корм/игра/сон
  (анимации + тосты «Ням!»); сеть — очередь tc-10.

## Что сделано
- `CritterView.tsx`: tokenURI через viem (`readContract`, ABI inline,
  chain baseSepolia), адрес из `import.meta.env.VITE_CRITTER_ADDRESS`;
  состояния waiting / loading / ready / sleepy — все нежные по доктрине
  («Ждём-ждем деплоя…», «Пухлик зазевался — попробуем ещё разочек?» с кнопкой
  повтора); до деплоя сцена живёт на милейшей заглушке-желейке (мигает, бобит).
- `Toast.tsx`: `CareAction`, милые реплики (`CARE_LINES`), хук `useCareToasts`
  (авто-удаление 2.4с, максимум 3 в стаке), виджет `Toasts` (aria-live, без
  перехвата кликов).
- `App.tsx`: кнопки-стабы «Покормить / Поиграть / Уложить спать» — локальные
  реакции: анимация пухлика (nom-nom / wiggle / lull, 2-сек сброс) + тост.
- `App.css`: пастель сохранена, докручены тосты-пузырьки (3 тона), кнопки
  «желе» с мягкой тенью и 3D-прожимом, анимации реакций; всё под
  `prefers-reduced-motion`.
- env: `packages/web/.env.example` (+`VITE_CRITTER_ADDRESS`, `VITE_RPC_URL`),
  типизация в `src/env.d.ts`; секретов нет — только публичный адрес контракта.
- Зависимость `viem` добавлена — единственная новая (прямо указана тикетом,
  нужна и tc-10).
